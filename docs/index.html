为什么需要它？

传统知识管理的三个痛点，本方案逐一解决

  • ChatGPT 没有长期记忆 — 每次对话从零开始，存不下你的知识积累
  • 笔记软件不会整理 — 收藏一堆，但没人帮你归类、去重、建索引
  • 数据在云端不放心 — 个人笔记、采集的社交内容，不想全交给云服务

💡 本方案的回答

AI 自动整理 — 文章、PDF、截图丢给 AI，自动归类成结构化笔记

永久本地记忆 — 笔记存在你电脑，AI 对话时才发送给模型服务商

定期自动体检 — AI 检查死链、重复、孤岛页面，保持知识库健康

四个 AI agent 自由切换，规则和技能全部共用

知识库结构

清晰的目录职责，raw 永不改，wiki AI 维护

# 部署后的知识库 我的知识库/ ├── AGENTS.md # AI 规则（系统维护） ├── AI_CONFIG.md # ⚙️ 用户可自定义配置 ├── raw/ # 原始素材（AI 只读） │ └── social/ # 按知识域分类 ├── wiki/ # AI 整理的笔记 │ ├── index.md # 全局索引 │ └── log.md # 操作日志 ├── assets/ # 配图资源 └── .opencode/skill/ # 9 个预装技能 # (claude→.claude/skills) # (codex/pi→用户级)

📦 raw/ — 不可变原始素材

PDF、文章、截图、社交内容原样保存。AI 只读，永不修改，保证可追溯。按知识域分子目录。

📝 wiki/ — AI 维护的消化笔记

AI 整理后的结构化笔记。同主题自动合并，跨主题交叉引用。index.md 全局索引，log.md 操作日志。

🛠️ .opencode/skill/ — 预装技能

9 个技能（obsidian-cli、opencli-usage、smart-search 等），内容四 agent 共用，按 agent 分发到对应目录。

常见问题

Q：我没有技术背景，能用起来吗？

完全可以。专为非技术用户设计，跟着部署指南一步步操作，不需要懂编程。也支持「让 AI 帮你部署」的零门槛方式。

Q：我的数据安全吗？

笔记文件保存在你自己电脑上，本项目不托管你的数据。使用 AI 时，当前对话内容会发送给你配置的模型服务商。raw/ 目录的原始素材永远不会被 AI 修改。笔记是普通 Markdown，随时可备份。

Q：四个 agent 怎么选？

大多数用户选默认的 OpenCode（6 大模型原生、体验最完整）。偏好 Anthropic 选 Claude Code，偏好 OpenAI 选 Codex，喜欢开源轻量选 Pi。四个都支持 claudian 插件在 Obsidian 内对话，规则技能完全共用。

Q：和直接用 ChatGPT 有什么区别？

ChatGPT 数据在云端、记忆是会话级、整理要手动。本方案数据本地、记忆永久、AI 自动整理归类、支持文件关联和交叉引用。

Q：想换 agent 或 provider 怎么办？

重跑 setup.sh 选新的即可，不会删除你已有的 raw/ wiki/ 笔记。详见 docs/agents.md 的切换指南。
