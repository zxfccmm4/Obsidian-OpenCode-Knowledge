常见问题。

没有技术背景能用吗？

完全可以。专为非技术用户设计，跟着部署指南操作不需要懂编程。也支持「让 AI 帮你部署」的零门槛方式。

我的数据安全吗？

笔记存在你自己电脑上，本项目不托管数据。使用 AI 时当前对话内容会发送给你配置的模型服务商。raw/ 原始素材永不被修改。

四个 agent 怎么选？

大多数用户选默认的 OpenCode。偏好 Anthropic 选 Claude Code，偏好 OpenAI 选 Codex，喜欢开源轻量选 Pi。四个都支持 claudian 插件在 Obsidian 内对话。

和直接用 ChatGPT 有什么区别？

ChatGPT 数据在云端、记忆是会话级、整理要手动。本方案数据本地、记忆永久、AI 自动整理归类、支持文件关联和交叉引用。

想换 agent 或 provider？

重跑 setup.sh 选新的即可，不会删除你已有的 raw/ wiki/ 笔记。
