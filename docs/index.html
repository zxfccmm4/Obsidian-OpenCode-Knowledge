为什么需要它

// 06 DATA STRUCTURE

知识库结构

raw 永不改，wiki AI 维护

// 部署后的知识库 我的知识库/ ├── AGENTS.md // AI 规则（系统维护） ├── AI_CONFIG.md // ⚙️ 用户可自定义 ├── raw/ // 原始素材（AI 只读） │ └── social/ // 按知识域分类 ├── wiki/ // AI 整理的笔记 │ ├── index.md // 全局索引 │ └── log.md // 操作日志 ├── assets/ // 配图资源 └── .opencode/skill/ // 9 预装技能

▸ raw/ 不可变原始素材

PDF、文章、截图、社交内容原样保存。AI 只读永不修改，保证可追溯。按知识域分子目录。

▸ wiki/ AI 维护笔记

AI 整理后的结构化笔记。同主题自动合并，跨主题交叉引用。index.md 全局索引，log.md 操作日志。

▸ .opencode/skill/ 预装技能

9 个技能（obsidian-cli、opencli-usage、smart-search 等），内容四 agent 共用，按 agent 分发。

// 09 FAQ

常见问题

Q // 没有技术背景能用吗

完全可以。专为非技术用户设计，跟着部署指南操作不需要懂编程。也支持「让 AI 帮你部署」的零门槛方式。

Q // 数据安全吗

笔记存在你自己电脑上，本项目不托管数据。使用 AI 时，当前对话内容会发送给你配置的模型服务商。raw/ 原始素材永不被 AI 修改。笔记是普通 Markdown，随时可备份。

Q // 四个 agent 怎么选

大多数用户选默认的 OpenCode。偏好 Anthropic 选 Claude Code，偏好 OpenAI 选 Codex，喜欢开源轻量选 Pi。四个都支持 claudian 插件在 Obsidian 内对话，规则技能完全共用。

Q // 和 ChatGPT 的区别

ChatGPT 数据在云端、记忆是会话级、整理要手动。本方案数据本地、记忆永久、AI 自动整理归类、支持文件关联和交叉引用。

Q // 想换 agent 或 provider

重跑 setup.sh 选新的即可，不会删除你已有的 raw/ wiki/ 笔记。详见 docs/agents.md。
