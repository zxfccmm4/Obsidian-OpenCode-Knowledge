你的第二大脑，
现在有了 AI。

一个本地 AI 知识库。文章、PDF、社交媒体内容自动整理成结构化笔记，支持四大 AI agent。

查看 GitHub 5 分钟部署

我们每天都在阅读、收藏、截图，但知识从来没有真正沉淀下来。ChatGPT 没有长期记忆，笔记软件不会整理，云端服务又让人不放心。

这个项目想解决的就是这件事：让 AI 帮你把零散的内容，变成一个永久保存在你电脑上的、结构化的知识库。

丢给它任何内容，它帮你归类、消化、建索引。

核心能力

一句话描述你的意图，AI 全自动完成整理、归类、查询和体检。四个触发词，覆盖知识管理的完整流程。

📥

自动录入 Ingest

文章、PDF、截图丢给 AI，自动存原始素材，整理成结构化 wiki 笔记，更新索引和日志。

「加到 wiki」
📱

社交采集 Social Ingest

小红书、抖音、Twitter、微博内容，一键归类、去口语、评估可信度，同主题自动合并。

「收录这条」
🔍

智能查询 Query

像聊天一样问「我写过关于 XX 的内容吗」，AI 从索引定位，合成答案并引用来源。

「wiki 里有没有」
🏥

定期体检 Lint

每周一次，AI 检查索引一致性、死链、孤岛页面、事实矛盾，发现问题自动修复。

「lint wiki」

四大 AI Agent

同一套规则与技能，按你的偏好选择 agent。部署时用 --agent 指定，四个 agent 都能在 Obsidian 内直接对话。

⚡
推荐

OpenCode

--agent opencode

6 大模型原生支持。配置最简单。

🅒

Claude Code

--agent claude-code

Anthropic 官方。推理能力最强。

◎

Codex

--agent codex

OpenAI 官方。生态最开放。

π
新增

Pi

--agent pi

开源轻量。支持 15+ provider。

🔌 通过 claudian 统一插件，四个 agent 都能在 Obsidian 内直接对话，一行配置搞定。

数据结构

知识库有清晰的目录职责。原始素材（raw/）AI 只读永不修改，保证可追溯；wiki/ 由 AI 维护，同主题自动合并，跨主题交叉引用。

# 部署后的知识库 我的知识库/ ├── AGENTS.md # AI 规则（系统维护） ├── AI_CONFIG.md # ⚙️ 用户可自定义配置 ├── raw/ # 原始素材（AI 只读） │ └── social/ # 按知识域分类 ├── wiki/ # AI 整理的笔记 │ ├── index.md # 全局索引 │ └── log.md # 操作日志 ├── assets/ # 配图资源 └── .opencode/skill/ # 9 个预装技能
